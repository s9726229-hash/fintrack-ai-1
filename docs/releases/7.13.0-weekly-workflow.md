# 7.13.0 每週記帳工作流程

## 調整內容

- 固定收支支援編輯、暫停、恢復及結束，修改時保留識別碼、既有帳目和執行紀錄。
- 暫停／結束不再自動入帳，不計入總覽與預算的固定收支推估。恢復只處理本期到期項目，不補過去月份。舊備份未指定狀態時視為啟用。
- 既有固定項目的頻率不可直接切換；如需改頻率，結束後新增項目。結束項目仍可查閱，不提供直接恢復。
- 股息批次入帳先確認實收金額及日期，不以除息日代替未知發放日；拒絕非正數金額、無效或未來日期。
- 新股息以固定交易 ID 防重，入帳狀態及金額取自交易。刪除後可重新確認，刪除復原不會覆蓋已重新建立的同 ID 交易。舊版 recorded 標記保留相容，不自動猜測歷史交易關聯。
- 設定顯示本裝置最近手動匯出、最近雲端備份成功時間；總覽與設定在尚無紀錄或滿 7 天時提醒。匯出僅代表送出下載，仍須確認檔案保存。
- Google Drive 改標示「備份與還原」，明確提醒非即時同步、還原為完整取代。
- 匯入忽略欄位區分憑證、本機設定、停用技術分析參數及未知欄位，可展開檢視欄位名稱。

本階段不新增帳戶連結、轉帳、對帳或自動資金異動。
